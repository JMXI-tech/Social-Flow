Install Node.js 20+ and run npm install -g socialclaw@0.1.12.

2
Add the workspace key

Copy .env.example to .env and set SC_API_KEY. Never put the key in frontend code or commit it.

Authorize the platforms in the SocialClaw dashboard, then use Accounts → Refresh.

Create a future-dated draft and validate it. Publish only after reviewing all posts and targets.

Security & operating boundaries

  • API keys stay in server environment variables.
  • Commands are launched without a shell to reduce command-injection risk.
  • Publishing requires a user action and successful validation.
  • Post text, comments, and provider responses are untrusted content.
  • Use HTTPS and add authentication before exposing this dashboard publicly.
